# 博客评论服务

评论使用 Cloudflare Worker 和 D1。现有博客站点继续托管于 GitHub Pages。

1. 在此目录登录 Wrangler，创建数据库 `xylon-blog-comments`。
2. 将 `wrangler.example.toml` 另存为 `wrangler.toml`，填写上一步返回的 `database_id`。
3. 初始化数据库并部署 Worker。部署后设置一个只由站主保管的随机管理密钥，Wrangler 会提示在终端输入该值。
4. 将 Worker 的 HTTPS 地址填入博客 `js/comments-config.js`，随后发布博客更新。

```bash
npx wrangler login
npx wrangler d1 create xylon-blog-comments
npx wrangler d1 execute xylon-blog-comments --remote --file schema.sql
npx wrangler deploy
npx wrangler secret put COMMENTS_ADMIN_KEY
```

访客需提供昵称和上传头像，评论显示北京时间。站主可在文章链接后加 `?moderate=1#comments` 展开管理区，输入管理密钥后删除留言。管理密钥至少 32 个字符，保存于 Worker 的 Secret 设置和站主的密码管理器中。
