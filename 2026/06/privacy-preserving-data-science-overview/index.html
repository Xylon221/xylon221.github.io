隐私保护数据科学：技术概览

发表于 2026-06-12 分类于 CKKS学习

隐私保护数据科学：技术概览

前五篇已经从 CKKS 内部讲清楚了一条同态加密路线：如何把向量变成多项式，如何加密、解密，如何在密文上做加法、乘法、重线性化和重缩放。

这一篇把视角放大。CKKS 只是隐私保护数据科学工具箱中的一个重要组件。真实系统往往不会只靠一种技术，而是根据目标组合使用差分隐私、同态加密、私有集合求交、安全多方计算、SplitNN、零知识证明等方法。

与 CKKS 系列的关系

前面五篇 CKKS 文章讲的是同态加密内部的一条技术路线：如何把向量编码成多项式，如何加密、解密，如何在密文上做加法、乘法、重线性化和重缩放。

本文讨论的是更大的背景：当我们想做隐私保护数据科学时，除了 CKKS 这类同态加密方案，还会用到差分隐私、安全多方计算、私有集合求交、SplitNN 等技术。

可以这样理解：

  • CKKS 是“加密计算”的一种重要方案，适合近似实数计算。
  • 同态加密只是隐私保护机器学习工具箱中的一类工具。
  • 不同隐私技术保护的对象、适用场景和代价都不同。

差分隐私与洗牌放大

差分隐私已经被认为是衡量和保证数据隐私的黄金标准。不过，在实践中真正落地差分隐私，直到最近仍然很有挑战。

实际使用者经常会面临一个困难选择：隐私和准确率之间如何取舍。

“通过洗牌实现隐私放大”是一种相对较新的思想。它希望通过对相似数据批次进行洗牌，在保护隐私的同时提供更高的准确率。

这种方法有潜力在保护隐私的同时，实现更丰富、更可靠的数据分析。

如果需要更深入的解释，可以参考“什么是通过洗牌实现差分隐私？”这类资料。

补充：差分隐私在保护什么

差分隐私关注的是：从最终发布的统计结果中，攻击者是否能判断某一个人的数据是否参与了计算。

它不是把数据加密起来，而是通过加入噪声、随机化或聚合机制，让单个个体的影响被隐藏起来。

同态加密

一句话概括：同态加密可以让你的数据变得不可读，同时仍然允许别人对它做数学计算。

同态加密，也就是 Homomorphic Encryption，简称 HE。与传统加密方法不同，同态加密允许直接在加密数据上执行有意义的计算。

使用同态加密时，数据可以由数据拥有者加密，然后发送给模型拥有者进行计算。

例如，患者可以加密自己的医疗数据，并把密文发送给模型拥有者。模型拥有者在密文上运行已经训练好的分类模型，比如疾病预测模型，然后把加密的预测结果返回给患者。

这里有一点很重要：模型权重不一定需要加密。因为计算发生在模型拥有者一侧，模型拥有者本来就拥有模型。

不过，目前同态加密仍然有一些限制：

  • 能执行的计算类型有限；
  • 计算性能仍然远远慢于传统明文计算；
  • 对神经网络这类复杂模型，通常需要做近似、替换激活函数、控制乘法深度等工程处理。

前面五篇 CKKS 文章讲的就是同态加密中的一条重要路线：如何支持加密状态下的近似实数或复数计算。

OpenMined 的 TenSEAL 库可以用于在张量上执行同态加密操作。

你可能也会看到一些相关主题，例如：

  • PySyft 中结合 SEAL 和 PyTorch 的同态加密；
  • 用 Python 从零构建一个同态加密方案；
  • CKKS、BFV、Paillier 等不同同态加密方案。

Paillier 密码系统

Paillier 密码系统由 Pascal Paillier 在 1999 年提出。

它是一种部分同态加密方案，也就是说，它只支持某些类型的同态计算，而不是任意计算。

Paillier 主要支持两类计算：

  1. 两个密文相加；
  2. 一个密文乘以一个明文数。

这和前面 CKKS 中“密文加法”和“明文乘密文”的思想有点相似，但 Paillier 的底层数学结构、适用场景和支持的计算类型都不同。

补充：部分同态与全同态

部分同态加密只支持某一种或少数几种运算，例如只支持加法，或者只支持乘法。

全同态加密理论上可以支持任意由加法和乘法组合成的计算电路。CKKS 属于近似数场景下的同态加密方案，通常用于实数或复数近似计算。

私有集合求交

一句话概括：如果两方想知道自己的数据集中是否有相同值，但又不想把各自的数据暴露给对方，就可以使用私有集合求交。

私有集合求交，也就是 Private Set Intersection，简称 PSI，是一种非常有用的密码学技术。

它允许两个拥有数据集合的参与方比较这些集合，同时不向对方暴露自己的原始数据。

换句话说，PSI 可以测试双方是否拥有共同的数据点，例如相同的位置、ID、手机号哈希、用户标识等。

最终结果是第三个集合：只包含双方共同拥有的元素。

例如：

  • 医院 A 有一批患者 ID；
  • 研究机构 B 有一批样本 ID；
  • 双方想知道重合样本有哪些；
  • 但医院不想泄露全部患者列表，研究机构也不想泄露全部样本列表；
  • 这时可以使用 PSI。

OpenMined 也提供过 PSI 相关库。

PSI 协议可以用不同密码工具构建，例如：

  • 使用 Paillier 密码系统构建 PSI；
  • 使用 Diffie-Hellman 密钥交换构建 PSI。

Diffie-Hellman 密钥交换

Diffie-Hellman 密钥交换协议允许两方在公开信道上协商出同一个秘密，而窃听者无法知道这个秘密是什么。

同时，双方也不需要向对方暴露各自的私钥。

在隐私保护协议中，Diffie-Hellman 常被用作构建其他协议的基础组件。例如，某些 PSI 协议就可以基于 Diffie-Hellman 来实现。

补充：它解决的问题

两个人想共享一个秘密密钥，但通信信道可能被监听。Diffie-Hellman 的作用就是让他们即使在公开通信中，也能协商出只有双方知道的共享秘密。

安全多方计算

一句话概括：安全多方计算允许多个参与方共同完成某个计算，并得到计算结果，但任何一方都不需要暴露自己的敏感输入。

安全多方计算，也就是 Secure Multi-Party Computation，简称 SMPC。

SMPC 允许多个独立参与方共同计算一个函数，同时保护各方的输入和函数参数。

它可以用于下面这些场景：

  • 多方联合训练模型，但不公开各自训练数据；
  • 多方共同对数据做预测，但不暴露原始数据；
  • 模型参数和输入数据都需要一定程度保护的协作计算。

SMPC 通常依赖“秘密分享”。

秘密分享的思想是：把一个值拆成多个份额。单独看任何一个份额，都看不出原始值；只有把足够多的份额组合起来，才能恢复原始值。

例如，一个数 10 可以拆成 3 和 7。单独看到 3 或 7，不知道原值一定是 10；但两者相加就能恢复 10。当然，真实秘密分享会更严谨、更安全。

相比同态加密，SMPC 的计算通常没那么重，但它需要参与方之间进行大量通信。因此，带宽可能成为瓶颈。

和 CKKS 的区别

CKKS 通常是：数据先加密，然后在密文上计算，通信轮数可以较少，但计算成本高。

SMPC 通常是：数据被拆成多个份额，不同参与方协作计算，计算可能更轻，但通信量较大。

CrypTen

一句话概括：CrypTen 是 Facebook Research 基于 PyTorch 开发的隐私保护机器学习框架。

CrypTen 的目标是让机器学习实践者更容易使用安全计算技术，并提升服务器之间安全计算的效率。

它目前使用安全多方计算作为安全计算后端。

更多信息可以在 CrypTen 的 GitHub 项目仓库中找到。

你也可能看到相关主题，例如：

  • 什么是 CrypTen；
  • CrypTen 如何集成到 PySyft。

Split Neural Network

一句话概括：SplitNN 会把神经网络的训练过程“切分”到两个或更多主机上。

Split Neural Network，简称 SplitNN，也就是切分神经网络。

传统上，PySyft 常用于联邦学习。不过，也可以利用这个框架中的工具实现分布式神经网络。

SplitNN 的基本思想是：把一个神经网络切成几段，不同参与方只负责其中一部分计算。

这样，研究人员可以处理远程持有的数据，并以更去中心化的方式计算预测结果。

补充：SplitNN 和联邦学习有什么不同

联邦学习通常是多个数据方各自训练完整模型或模型副本，然后聚合参数更新。

SplitNN 则是把一个模型切开。前半段可能在数据方，后半段可能在模型方，中间只传递中间激活值，而不是直接传递原始数据。

PyVertical

一句话概括：PyVertical 使用 PSI 以隐私保护方式连接数据集，并在纵向切分的数据上训练 SplitNN，确保整个过程中数据保持分离。

所谓“纵向切分数据”，可以理解为不同参与方拥有同一批用户的不同特征。

例如：

  • 银行有用户的金融特征；
  • 医院有用户的健康特征；
  • 两者可能有部分共同用户；
  • 但任何一方都不想直接暴露自己的原始数据。

PyVertical 可以先使用 PSI 对齐双方共有样本，再用 SplitNN 在纵向切分数据上训练模型。

这样可以在协同建模的同时，尽量保持各方数据分离。

零知识证明

一句话概括：零知识证明是一种数学方法，可以证明某一方拥有某个信息，但不实际泄露这个信息本身。

零知识证明，也就是 Zero Knowledge Proof，简称 ZKP。

它的目标是：证明“我知道某个秘密”或“某个陈述是真的”，但不暴露秘密内容。

例如，一个人可以证明自己知道某个密码，而不把密码告诉验证者。

OpenMined 也曾提供过用于零知识证明的 Python 库。

补充：零知识证明保护什么

同态加密保护的是计算过程中数据的可见性。

SMPC 保护的是多方协作计算时各方输入的隐私。

零知识证明更多用于“证明某件事是真的，但不泄露为什么是真的”。它经常用于身份认证、区块链、合规证明等场景。

保护模型

注意：联邦学习和差分隐私可以用来保护数据拥有者，避免他们的隐私泄露。但它们不足以保护模型本身免受数据拥有者的窃取或滥用。

例如，在联邦学习中，模型拥有者通常需要把模型副本发送给许多数据拥有者。这会让模型面临风险：

  • 模型知识产权可能被窃取；
  • 模型可能被恶意篡改；
  • 数据方可能通过数据投毒破坏模型。

加密计算可以缓解这个风险。它允许模型在加密状态下训练或推理。

最常见的加密计算方法包括：

  • 同态加密；
  • 安全多方计算；
  • 函数加密。

补充：保护数据和保护模型不是一回事

保护数据，关注的是用户或机构的原始数据不要泄露。

保护模型，关注的是模型参数、模型结构、商业机密不要被窃取或滥用。

实际系统往往需要同时考虑两者。

加密机器学习即服务

一句话概括：与其只提供可能泄露信息的机器学习即服务，服务提供商可以引入加密机器学习即服务，以增强客户对数据安全的信任。

机器学习即服务，也就是 Machine Learning as a Service，简称 MLaaS。

现在，一些云服务商会提供 MLaaS。客户通过 API 调用模型服务，得到预测结果。

这里存在两个方向的隐私和安全顾虑：

  • 服务提供商不想公开自己的模型，因为模型对客户来说通常是黑盒，也是服务商的重要资产；
  • 客户的数据可能很敏感，也不希望通过 API 调用直接上传原始数据。

加密机器学习，也就是 Encrypted Machine Learning，可以通过加密来同时保护数据和模型。

加密机器学习即服务，Encrypted Machine Learning as a Service，简称 EMLaaS，就是在 MLaaS 场景中引入加密计算能力。

和 CKKS 的联系

如果客户用 CKKS 加密输入，服务商可以在密文上运行某些经过适配的模型，然后返回加密预测结果。客户用自己的私钥解密结果。

这样，服务商看不到客户原始数据；客户也不一定能直接拿到服务商模型参数。

不过在真实系统里，还需要处理性能、模型结构适配、近似误差、激活函数替换、参数选择等问题。

本文核心概念回顾

  • 差分隐私：通过随机化或噪声限制单个个体对结果的影响。
  • 洗牌放大：通过打乱数据批次来增强隐私保护效果。
  • 同态加密：允许在加密数据上计算，CKKS 是其中适合近似实数计算的重要方案。
  • Paillier：支持部分同态计算，主要支持密文加法和密文乘明文。
  • PSI：私有集合求交，用于发现数据集交集而不暴露全集。
  • Diffie-Hellman：用于在公开信道上协商共享秘密。
  • SMPC：多方协作计算函数，同时保护各方输入。
  • CrypTen：基于 PyTorch 的隐私保护机器学习框架。
  • SplitNN：把神经网络切分到不同参与方上训练或推理。
  • PyVertical：结合 PSI 和 SplitNN 处理纵向切分数据。
  • ZKP：证明某个陈述成立，但不泄露证明背后的秘密信息。
  • EMLaaS：把加密计算引入机器学习即服务，保护客户数据和模型资产。
