# 书房私人同步

公开书房托管在 GitHub Pages。待办和随笔通过 HTTPS 请求服务器上的同步服务。Python 服务只监听 127.0.0.1:8786，Nginx 在已有可信 HTTPS 证书的虚拟主机中转发 /reading-room-sync/。

## 部署

1. 将 server.py 和 schema.sql 放入 /opt/reading-room-sync/。
2. 以 root 创建目录 /etc/reading-room-sync/，权限设为 0700。用 Python 的 secrets.token_urlsafe(32) 生成一次站主密钥，保存为 owner.key，权限设为 0600。升级时保留这个文件。
3. 将 reading-room-sync.service 放入 /etc/systemd/system/。如博客域名变了，修改其中的 DESK_SITE_ORIGIN，然后运行 `sudo systemctl daemon-reload` 和 `sudo systemctl enable --now reading-room-sync`。更新服务代码后重启该服务。
4. 将 reading-room-sync.conf 放入 /etc/nginx/snippets/。在既有 HTTPS 虚拟主机的 server 块内加入 `include /etc/nginx/snippets/reading-room-sync.conf;`，运行 `sudo nginx -t` 后重新加载 Nginx。
5. 把接口地址填入 js/desk-config.js，更新 js/room-widgets.js 中配置的版本号和页面引用脚本的版本号，然后发布博客。

SQLite 数据库由 systemd 管理，路径为 /var/lib/reading-room-sync/desk.sqlite3。需要备份时，通过 SQLite 的在线备份接口生成一致快照。首次登录时，在自己电脑上通过 SSH 读取站主密钥，保存到密码管理器。每台设备首次打开书房时，用同一个密钥登录。
